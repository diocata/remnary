# Native dependency baseline

Verified locally on 2026-10-20:

| Component | Selected implementation | Evidence |
| --- | --- | --- |
| SQLCipher | 4.19.0 community | Runtime `PRAGMA cipher_version`; encrypted integration/recovery tests |
| SQLite | 3.53.4 | Runtime `sqlite_version()`; migration/FTS/integrity tests |
| Crypto on macOS | Apple CommonCrypto | Runtime `PRAGMA cipher_provider`; binary links only system libraries/frameworks |
| Rust SQL bindings | Official rusqlite Git revision `661107f6eb5d7477c61be1221744de3ad96c53e7` | Cargo manifest and lockfile pin the complete revision |
| Native source crate | `sqlcipher-src 419.0.6+sqlcipher-4.19.0-sqlite-3.53.4-libtomcrypt-1.18.2` | Registry checksum in Cargo.lock |

The earlier registry bindings bundled SQLCipher 4.14.0. The pinned upstream revision integrates the newer source crate; its Rust package version labels are 0.40.1/0.38.1, while the previous registry packages were 0.40.2/0.38.2. The native engine upgrade is established by runtime checks, not those Rust labels. This is an unreleased upstream pin: review changes before updating it, retain the exact revision and rerun compatibility checks. No branch name or mutable Git tag is used.

The default macOS build uses `bundled-sqlcipher` with CommonCrypto; OpenSSL source/bindings have been removed from this lockfile. Custom build-environment OpenSSL overrides can change the provider. Check `doctor` and `otool -L` for a release build. Linux requires appropriate system crypto headers/libraries; Linux/Windows are not validated release targets. [Platform policy](platforms.md).

SQLCipher's [4.19 release announcement](https://www.zetetic.net/blog/2026/09/08/sqlcipher-4.19.0-release/) identifies export-alias escaping and invalid `hexkey` URI handling fixes. Remnary applies raw keys through the C API, binds paths and uses fixed export aliases, but still upgrades the native baseline. SQLCipher 5 beta is not selected. SQLCipher-specific pragmas use fixed SQL literals because the pinned Rust helper validates dynamic pragma names against SQLite's list, which omits the encryption extensions.

All 142 automated tests passed with the new engine/provider. A backup generated by the previous SQLCipher 4.14/OpenSSL build restored successfully with SQLCipher 4.19/CommonCrypto, preserved its original file hash and passed schema-4 integrity/foreign-key checks. Release-binary SIGKILL/retry checks for backup, restore and plaintext conversion passed again. Cargo-audit 0.22.2 reported zero vulnerabilities/warnings in 189 locked dependencies against RustSec commit `999ec89d5d3f10f20be14750ec8c2d8b44e0ac9b` (2026-10-17); it does not audit the C amalgamation or prove security.

Native notices are preserved under [third_party/notices](../third_party/notices/). The source crate includes LibTomCrypt material even though this macOS build selects CommonCrypto; its notice is retained. A complete Rust/toolchain dependency-notice inventory and independent security review are separate from this native upgrade evidence.
