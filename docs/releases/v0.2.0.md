Remnary's first downloadable cross-platform release: Windows, Linux and macOS, on x86-64 and ARM64.

**Download the archive matching your operating system and CPU below.** Windows uses ZIP; Linux and macOS use tar.gz. Extract it and run `remnary --help` (`.\remnary.exe --help` in PowerShell). No Rust installation or separate database/crypto service is required to run the binary.

- Every target runs the locked test suite, formatting, Clippy, an optimized native build and a packaged-executable smoke workflow before publishing.
- The smoke check covers encrypted import/reimport, rules, review/profile, annotation-preserving Markdown, search, backup/restore, Unicode paths and authenticated localhost HTTP.
- Windows and Linux bundle SQLCipher with statically built OpenSSL. Windows packages use a static MSVC runtime. macOS uses CommonCrypto and an ad-hoc signature.
- macOS Keychain and Windows Credential Manager provide native key storage. Linux uses an explicitly created private key file; pass `--key-file` with each archive command.
- Windows path exclusions and Kiro's standard source locations now work across hosts. Existing archives, evidence IDs, backups and the original development formats stay compatible.
- Both project licenses, target-specific dependency notices, artwork, guides and a fictional demo are included.

## Platforms and integrity

Build/test runners: Ubuntu 22.04 (x64/ARM64), Windows Server 2022 (x64), Windows 11 (ARM64), macOS 15 (Intel) and 26 (Apple Silicon). Linux binaries require glibc 2.35 or later; musl/Alpine is not covered. macOS builds target 13.0 or later; CI runtime checks run on macOS 15 (Intel) and 26 (Apple Silicon). This is not a promise about every OS version or 32-bit machine.

Check the matching `.sha256` file or combined `SHA256SUMS`. Each archive's `BUILD.json` records source commit, target, toolchain, binary hash and tested environment.

These binaries are unsigned on Windows and ad-hoc signed/unnotarized on macOS. No Developer ID, Authenticode certificate, installer or automatic updater is included. Build from source if your OS policy requires a signed/notarized distribution.

See the repository README for installation, Linux key-file examples and the demo. Findings remain reviewable candidates; only explicit confirmation/correction adds them to your personal profile.
